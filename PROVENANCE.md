# Provenance Record

This repository was initialized as a new Git repository on 2026-09-13. Its
source, history, notices, and license text are maintained independently.

The functional requirements are deliberately ordinary and documented here:
capture mono PCM, detect speech locally, transcribe it locally, and type the
result on a Wayland desktop. The Wayland output behavior preserves the
maintainer's independently authored handling for virtual-keyboard warmup and
leading spaces; it was written anew in this repository.

Before publishing binaries or bundling models, maintainers must verify the
licenses of the exact dependency and model versions they distribute.
